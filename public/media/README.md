# Media files for the Mirodil Hayitov website

Use the prepared ZIP package named mirodil-complete-media.zip.

The following ten files must be uploaded to public/media:

Television and newspaper:
- interview-ozbekiston24.jpeg
- interview-mahalla.jpg
- press-yoshlar-ovozi-cover.jpg
- press-yoshlar-ovozi-feature.jpg

Privacy-redacted exam scans:
- certificate-ielts-redacted.webp
- certificate-sat-redacted.webp
- certificate-math-redacted.webp

New awards:
- award-english-district-2026.webp
- award-chess-spartakiad-2022.webp
- award-boxing-tashkent-2025.webp

Upload the image files directly, not the ZIP. On GitHub open the public/media folder and select Add file -> Upload files. Commit all ten files to main. The connected host may redeploy automatically.

The English award goes on the Education page. Chess and boxing belong on Activities. The original diploma classification and handwritten placement in the chess award are presented as different values. The documents are subject-provided and are not independently authenticated.

Do not publish original exam images containing identification numbers, QR codes, private details or portraits. The exam scans in the prepared archive are irreversibly masked. The new award photos already have selective concealment by the uploader and were optimized as WebP for the web.
